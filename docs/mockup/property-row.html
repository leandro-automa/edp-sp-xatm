xatm_PropertyRow — especificação visual

Um único XControl. O que ele mostra é decidido por PropertyType e pelos bits de Exposure. A linha tem 16 px — uma grade densa de inspetor, e é essa altura que decide todo o resto: nada empilhado, nenhum campo com borda, nenhum espaçamento vertical.

O que 16 px custa. O botão de ícone cai para 14 px, muito abaixo dos 44 px recomendados para toque — aceitável só porque este painel é operado com mouse em estação de engenharia. O texto da linha cai para 11 px, abaixo dos 16 px recomendados para corpo de texto; vale para uma grade de inspetor lida em varredura, não para leitura corrida. O contraste, esse, não cede: #0F172A e #475569 continuam em 15,9:1 e 7,4:1. Numa tela sensível ao toque, subir a linha para 28–32 px e o botão para 24 px.
